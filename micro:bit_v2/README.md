# micro:bit V2 Overview

The **micro:bit V2** is a compact, **versatile microcontroller board** designed for **education, IoT projects, and wireless security research**. Developed by the **BBC in collaboration with major tech companies**, it features an **nRF52833 Bluetooth SoC**, making it useful for **Bluetooth Low Energy (BLE) testing, IoT development, and hardware security experiments**.

## **Key Features**

- **Processor:** Nordic **nRF52833** (64 MHz ARM Cortex-M4F)
- **Wireless Protocols Supported:**
  - **Bluetooth 5 (BLE 5.0/5.1/5.2)**
  - **2.4 GHz RF Communication (nRF24-based)**
  - **Zigbee & Thread (Experimental Support)**
- **Built-in Sensors & Inputs:**
  - 5x5 **LED matrix display**
  - **Capacitive touch sensor**
  - **Motion detection** (accelerometer & gyroscope)
  - **Microphone & speaker** for audio projects
- **Connectivity:**
  - **USB interface for programming & debugging**
  - **Edge connector** for external expansion
- **Battery & Power Management:**
  - **3V coin cell or LiPo battery support**
  - **Low power consumption** for IoT applications
- **Programming Support:**
  - **MicroPython, C++, JavaScript, MakeCode, Scratch**

## **Use Cases in Wireless Security & IoT Research**

The **micro:bit V2** is widely used for **wireless security testing, IoT hacking, and penetration testing**. Below are some key applications:

### **1️⃣ Bluetooth Sniffing & MITM Attacks**
- Captures **BLE advertisement packets and pairing requests**
- Assists in **Bluetooth MITM (Man-in-the-Middle) attacks**
- Useful for testing **BLE-based access control systems**

### **2️⃣ Bluetooth Device Tracking & Enumeration**
- Scans for **BLE beacons, fitness trackers, and IoT devices**
- Logs **device advertising data** and signal strength (RSSI)
- Identifies potential **Bluetooth tracking devices**

### **3️⃣ Wireless Input Device Exploits**
- Can **sniff and inject keystrokes** into BLE-based keyboards
- Works with **nRF24-based mouse/keyboard hijacking**
- Exploits weak security in **BLE HID (Human Interface Devices)**

### **4️⃣ IoT Security Research & Exploitation**
- Tests **smart home devices, Zigbee hubs, and IoT sensors**
- Explores vulnerabilities in **BLE and custom RF communication**
- Works as a **low-power beacon for IoT automation**

### **5️⃣ Embedded Security & Hardware Hacking**
- Runs **custom firmware** for security testing
- Analyzes **low-level communication protocols** (SPI, I2C, UART)
- Interfaces with external **RF hacking tools** (Flipper Zero, Yard Stick One, Ubertooth)

## **Software & Tools**
- **MicroPython & uBit BLE API:** Bluetooth scripting & testing
- **Bettercap BLE Modules:** BLE security testing
- **BtleJack & BLEAH:** BLE sniffing & packet analysis
- **MakeCode & Scratch:** Rapid prototyping for automation testing

## **Conclusion**
The **micro:bit V2** is a **versatile and affordable microcontroller** that extends beyond education into **wireless security research, Bluetooth penetration testing, and IoT hacking**. Its **BLE and RF capabilities** make it a valuable tool for **security researchers and hardware hackers**. 🚀
